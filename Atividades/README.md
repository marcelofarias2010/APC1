# Atividades — APC I (MDC118)

Propostas alinhadas ao plano de ensino (Unidades I–IV) e às aulas `Aula01` … `Aula15_16`.

| Item | Conteúdo | Momento sugerido | Modalidade |
|------|----------|------------------|------------|
| Atividade 01 | Algoritmos, tipos, variáveis e operadores | Após Aulas 01–05 | Individual |
| Atividade 02 | Entrada e saída formatada | Após Aulas 06–08 | Individual |
| Atividade 03 | Condicionais e repetição | Após Aulas 09–12 | Individual ou dupla |
| Atividade 04 | Vetores, strings, struct e enum | Após Aulas 13–16 | Individual ou dupla |
| Trabalho Final | Sistema integrando todo o semestre | Entrega com A2 (T) | **Dupla** (conforme plano) |

As pastas `Praticas/` continuam como roteiros guiados de laboratório (passo a passo).  
As `Atividades/` são **problemas para avaliar** (enunciado + critérios), sem “receita” completa.

Compilação sugerida (laboratório):

```bash
gcc arquivo.c -std=c99 -Wall -Wextra -lm -o programa
```
